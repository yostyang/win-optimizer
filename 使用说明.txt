Windows一键优化 v0.2 使用说明
================================

运行
----
1. 把整个文件夹复制到 Windows 10 / 11 电脑上（任意位置，例如桌面）。
2. 双击「启动.bat」。不需要安装任何东西。
3. 第一次打开会自动体检。需要管理员权限的修复（改 DNS、停用 HKLM 启动项）会弹出 UAC，你可以拒绝。

如果打不开
----------
- SmartScreen 拦截：点「更多信息」→「仍要运行」。
- 或者：右键 WinOptimizer.ps1 → 属性 → 勾选「解除锁定」→ 确定（启动.bat 也会自动尝试解除锁定）。
- 或者在 PowerShell 里执行：
    Get-ChildItem "<文件夹路径>" | Unblock-File
- 窗口一闪就没了：双击「调试启动（显示错误）.bat」，把出现的红字截图发我。

功能
----
- 顶部实时概览：CPU、可用内存、开机时长、健康分（每 3 秒刷新）。CPU 读不到时显示「—」，不会把失败伪装成 0%。
- 智能体检：内存、浏览器、VPN、DNS、启动项、动画、开机时间，以及 CPU 和电池相关建议。
  勾选后点「一键修复所选」。不会强制结束程序。
- CPU：整机持续偏高、某个普通程序占用过高时，可以降优先级或只关闭窗口。搜索索引 / Defender / Windows 更新 / OneDrive 若正在忙，只解释原因，不关服务。
- 资源排行：按内存或 CPU 排序。可把进程降为「低于正常」并恢复；「关闭窗口」只发送关闭请求。系统关键进程和本程序不能操作。
- 电源滑杆（Windows 10 电池图标）：更好的电池 / 更高性能 / 最佳性能。用电池时不建议「最佳性能」。最左档「最佳电池续航」是节电模式，会打开系统设置，不代为拨动。没有滑杆时才改经典电源计划。
- 优化建议：电源与电池、显示、启动与后台、通知与隐私、网络。每一项显示当前状态；能改的会先把原值记到 %LOCALAPPDATA%\WinOptimizer\undo.json，可单条恢复或全部恢复。
  通知和隐私那一组主要是少弹窗，对速度帮助很小。
  Edge 策略会先说明：应用后 Edge 显示「由你的组织管理」，恢复时删掉策略。
  临时文件会先列出，确认后优先放进回收站。
  Windows 11 才有的项目（例如小组件、动态刷新率）在 Windows 10 上显示「不适用」，不会报错。
  动态刷新率、视频播放省电、可选诊断数据、Surface 充电上限、固件更新只打开对应的设置或 Surface 应用。
- 开机启动：注册表 Run / RunOnce + 启动文件夹；停用 / 启用用的是任务管理器同一个开关，不删除任何东西。
- 浏览器：Chrome / Edge / Firefox / Brave / Opera / Vivaldi / 360 / QQ / 搜狗；「退出」= 关闭窗口，标签页会保存。
- 网络诊断：ping 阿里 DNS、1.1.1.1、百度各 8 次（延迟、丢包）；显示当前 DNS；
  一键设为阿里 DNS 223.5.5.5 / 223.6.6.6，修改前备份到 %APPDATA%\WinOptimizer\dns-backup.json，可一键恢复。
- 显示：一键开关窗口动画、透明效果；打开显示设置 / 视觉效果。
- 电池：电量、是否接电源。可生成电池报告和掉电诊断（不改设置）。Surface 充电上限请到 Surface 应用或 UEFI，本工具不改固件。

安全
----
- 不会自动结束程序、不会自动重启、不关 Defender、不关 Windows 更新、不改 DNS 服务器、不关 IPv6。
- 只有在你点按钮并确认后才修改。改过的项目可以恢复；临时文件放进回收站后不能从本工具自动还原。
- 界面跟随系统深色 / 浅色。
