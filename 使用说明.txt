Windows一键优化 v0.1 使用说明
================================

运行
----
1. 把整个文件夹复制到 Windows 10 / 11 电脑上（任意位置，例如桌面）。
2. 双击「启动.bat」。不需要安装任何东西。
3. 第一次打开会自动体检。需要管理员权限的修复（改 DNS、停用 HKLM 启动项）会弹出 UAC，你可以拒绝。

如果打不开
----------
- SmartScreen 拦截：点「更多信息」→「仍要运行」。
- 或者：右键 WinOptimizer.ps1 → 属性 → 勾选「解除锁定」→ 确定（启动.bat 也会自动尝试解除锁定）。
- 或者在 PowerShell 里执行：
    Get-ChildItem "<文件夹路径>" | Unblock-File
- 窗口一闪就没了：双击「调试启动（显示错误）.bat」，把出现的红字截图发我。

功能
----
- 顶部实时概览：CPU、可用内存、开机时长、健康分（每 3 秒刷新）
- 智能体检：内存吃紧 / 多个浏览器 / VPN 虚拟网卡 / DNS 不是阿里 / 启动项太多 / 窗口动画 / 太久没重启。
  勾选后点「一键修复所选」；涉及结束程序、停用启动项的项目只会带你到对应页面，由你自己选。
- 资源排行：按内存或 CPU 排序的前 40 个进程；选中后「结束所选进程」（会二次确认，先礼貌关闭，3 秒后才强制）。
- 开机启动：注册表 Run / RunOnce + 启动文件夹；停用 / 启用用的是任务管理器同一个开关，不删除任何东西。
- 浏览器：Chrome / Edge / Firefox / Brave / Opera / Vivaldi / 360 / QQ / 搜狗；「退出」= 关闭窗口，标签页会保存。
- 网络诊断：ping 阿里 DNS、1.1.1.1、百度各 8 次（延迟、丢包）；显示当前 DNS；
  一键设为阿里 DNS 223.5.5.5 / 223.6.6.6，修改前备份到 %APPDATA%\WinOptimizer\dns-backup.json，可一键恢复。
- 显示：一键开关窗口动画、透明效果；打开显示设置 / 视觉效果。
- 电池：电量、是否接电源。充电上限由品牌软件控制（联想 Vantage、MyASUS、戴尔 Power Manager 等），本工具不修改。

安全
----
- 不会自动结束程序、不会删除文件、不会自动重启。
- 只有在你点按钮并确认后才做修改；所有修改都可以改回来。
- 界面跟随系统深色 / 浅色。
